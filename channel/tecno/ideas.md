# Banco de ideas — canal tecno

Cada idea lleva su **gancho** (la tesis contraintuitiva), no solo el tema: un tema sin
ángulo no sostiene un vídeo. Ver `script-formats.md` para elegir el formato de guion
según el tipo, y no encadenar dos vídeos seguidos con el mismo formato.

Marcar aquí cuando una idea se produce, para no repetir.
